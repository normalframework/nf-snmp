# MIB files

Copied from the LibreNMS MIB collection (https://github.com/librenms/librenms/tree/master/mibs).
Each MIB keeps its author's copyright and license terms. They are used only by tests and tooling
(`test/unit/profiles-mib.test.js`, `tools/mib-oids.js`) to verify profile OIDs; the plugin never
loads them at runtime.
